# between — NOTES

## 이 구현에서 배울 것 5개
1. 섹션 5개를 **세로로 쌓아 두고 컨테이너 하나만 `translateY`** 한다 — 스크롤이 아니라 transform이라 위치가 항상 정수 배수로 딱 떨어진다.
2. 입력 권한을 `active` prop 하나로 내려보내면 **"지금 누가 입력을 받는가"가 한 곳에서 결정된다** — 각 컴포넌트가 스스로 판단하지 않는다.
3. `onEdge`는 자식이 부모에게 **제어권을 넘기는 프로토콜**이다. 단어가 끝나면 섹션이 넘어가고, 갤러리 연도가 끝나면 섹션이 넘어간다 — 부모는 자식 내부를 몰라도 된다.
4. `entryFrom`으로 **어느 방향에서 들어왔는지**를 알려 주면, 위에서 내려온 사용자는 첫 항목에서, 아래에서 올라온 사용자는 마지막 항목에서 시작한다.
5. 섹션을 떠나도 **언마운트하지 않는다** — 상태가 보존된다. 대신 비싼 것(rAF 루프)만 `active`로 끈다.

## 자주 나는 버그와 해결 3개
1. **섹션 전환 중에 입력이 쌓여 두세 칸씩 날아감** — 600ms 전환이 끝나기 전 휠·키가 계속 들어온다. `locked` 상태로 전환 시간만큼 모든 입력을 무시한다.
2. **WORDS / TIME × SPACE에서 휠이 두 군데서 동작** — 자식과 부모가 같은 이벤트를 각자 처리하면 단어도 넘어가고 섹션도 넘어간다. 부모의 휠은 `WHEEL_SECTIONS`(INTRO·CANVAS·END)에서만 켜고, 나머지는 `onEdge`로만 넘어가게 한다.
3. **점을 클릭한 뒤 Space를 누르면 두 칸 이동** — 포커스가 남은 버튼이 Space로 다시 눌린다. 클릭 핸들러에서 `blur()`로 포커스를 놓는다. `document.body.style.overflow`도 cleanup에서 원래 값으로 되돌려야 다른 페이지가 망가지지 않는다.
